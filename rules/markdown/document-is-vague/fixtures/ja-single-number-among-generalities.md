# 新しいダッシュボードのご紹介: もっと速く、もっと分かりやすく

このたび、ゼロから作り直した新しいダッシュボードをご紹介します。数ヶ月にわたる開発と、皆さまからいただいた数多くのフィードバックの成果です。

パフォーマンスは私たちが常に最優先してきたポイントで、新しいダッシュボードは全体を通してこれまでよりも大幅に快適な体験を実現しています。ページの読み込みは速くなり、グラフの描画はスムーズになり、画面遷移は瞬時に感じられるはずです。

内部的にはデータ層を作り直し、社内テストにおける平均ページ読み込み時間を 2.4 秒から 1.1 秒に短縮しました。

見た目もより洗練された、モダンな印象になるよう刷新し、余白の使い方や視覚的な階層を全体的に見直しました。すべての画面を、余計な要素を減らし、本当に大事なものに集中できるよう再検討しています。

見た目の刷新だけでなく、お客様が日々ダッシュボードをどう使っているかから見えてきたパターンをもとに、ワークフロー全体にも数え切れないほどの細かな改善を加えました。

新しいダッシュボードをきっと気に入っていただけると思いますし、皆さまの感想を聞くのを楽しみにしています。これはまだ始まりに過ぎず、この先数ヶ月でさらに多くのことをお届けする予定です。
